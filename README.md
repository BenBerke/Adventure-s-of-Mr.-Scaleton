# Adventures of Mr. Skeleton

![Unity Version](https://img.shields.io/badge/Unity-2021.3%2B-blue?logo=unity)
![Language](https://img.shields.io/badge/Language-C%23-blue)
![Platform](https://img.shields.io/badge/Platform-PC-lightgrey)

**Adventures of Mr. Skeleton** is a small 2D side-scrolling platformer with light metroidvania elements, developed in Unity.  
The project focuses on player movement, level interaction, dialogue systems, and a simple boss encounter.

---

## 🔍 CV Highlights (What I Built)

- Designed **hazard-based level mechanics** (spikes, traps, and environmental damage)
- Built a **simple projectile system** triggered by player input and facing direction
- Implemented a **boss fight** with health management and projectile-based combat
- Used **ScriptableObjects** for dialogue and gameplay configuration
- Integrated **Unity’s New Input System** for keyboard input

---

## 🎮 Game Overview

Players control Mr. Skeleton as they explore a compact 2D side-scrolling world inspired by metroidvania design.  
Gameplay focuses on platforming challenges, environmental hazards, NPC dialogue, and a final boss fight.

The project emphasizes clean gameplay logic and system structure over content scale.

---

## 🛠 Technical Details

- Engine: Unity 2022.3 LTS+
- Language: C#
- Rendering: Unity 2D (Sprites)
- Input: Unity New Input System
- Architecture: Modular gameplay scripts with ScriptableObject-based data
- Gameplay: Hazard-based level design and scripted boss encounter

---

## ✨ Core Features

- **2D Side-Scrolling Movement:** Responsive movement and jumping with collision handling
- **Environmental Hazards:** Spikes and traps that damage or reset the player
- **Boss Fight:** Projectile-based encounter activated by player input
- **Projectile System:** Directional shooting based on player facing
- **Dialogue System:** Text-based NPC and story dialogue
- **Metroidvania Elements:** Small interconnected level layout
